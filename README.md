# Tados Smart Technology

Tados Smart Technology is a modern online store for smart home and security products in South Africa. The website is designed to help customers discover, compare, and buy products such as smart locks, biometric door locks, alarm systems, smart switches, curtain automation kits, and ceiling speakers.

The site focuses on convenience and home security, offering a clean shopping experience with featured collections, new arrivals, category browsing, cart management, and secure checkout. It is built for customers who want practical, connected solutions to improve home safety, automation, and everyday living.

It also includes customer account features, order tracking, and support pages for shipping, returns, installation, warranty, and contact information.
